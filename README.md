# Google Classroom 評価自動送信 GAS

Google フォーム回答を元に採点結果を取り込み、Google Classroom の個別メッセージとして生徒へ返却するための Google Apps Script です。複数クラス、複数フォーム用スプレッドシートに対応し、未採点や送信エラーのリマインドメールも送れます。

固定ヘッダ前提だった旧版に対して、現在は設定シートで参照元を管理し、設定ダイアログから以下を設定できます。

- フォーム側の列名
- `評価データ` / `送信シート` の列構成
- Classroom に送る返信本文テンプレート

フォーム回答スプレッドシート URL、対象シート名の接頭辞、リマインドメール送信先は `設定シート` で編集します。

設定を保存すると、`評価データ` と `送信シート` は警告つきで再生成されます。

このスクリプトは、管理用スプレッドシートを 1 つ用意し、その中のメニュー操作または時間トリガーで運用する前提です。

## できること

- Google Classroom のアクティブなクラス一覧を取得
- 同期対象クラスの生徒一覧を一括取得
- 設定ダイアログで取り込み設定と返信テンプレートを編集
- 複数のフォーム回答スプレッドシートから採点済みデータを取り込み
- 送信先クラス・生徒情報をひも付けて送信用データを生成
- Google Classroom に個別メッセージとして評価を投稿
- 未採点、未送信、エラー件数を教員にメール通知
- 管理用シートのクリア

## 全体フロー

1. `1 初期設定シート作成` を実行し、`設定シート` に参照元を入力する
2. `設定を開く` から列設定と返信テンプレートを保存する
3. `クラス一覧` を取得する
4. 同期したいクラスの `同期対象(1)` 列に `1` を入れる
5. `生徒一覧` を取得する
6. `対応表` を作成する
7. 各フォーム回答スプレッドシートで採点する
8. `Form → 評価データ取り込み` を実行する
9. `評価データ → 送信シート生成` を実行する
10. `生徒へメッセージ送信（Classroom）` を実行する
11. 必要に応じて `未採点・エラーのリマインダー送信` を時間トリガーで回す

## 管理用スプレッドシートの構成

この GAS は、以下のシート名を前提に動作します。

### `設定シート`

`1 初期設定シート作成` で作成されます。フォーム回答スプレッドシート URL、対象シート名の接頭辞、リマインドメール送信先はこのシートで編集します。

主に次の内容を保持します。

- `REMINDER_TO`: リマインドメール送信先
- `FORM_SS`: フォーム回答スプレッドシート URL
- 基本列設定
  - メール列名
  - 名前列名
  - 送信状態列名
  - 対象シート名の接頭辞
  - 採点済み判定に使うフォーム側ヘッダ
    - 採点時に必ず入力され、生徒に送信する列を選択
  - 未採点判定はメール列名を使用
    - メールアドレス列を推奨
- 項目定義
  - テンプレート変数名
  - フォーム側ヘッダ
  - `評価データ` 列名
    - 空欄ならフォーム側ヘッダ名をそのまま使用
  - `送信シート` 列名
    - 空欄ならフォーム側ヘッダ名をそのまま使用
  - 項目タイプ
- 返信テンプレート

内部では `CONFIG_JSON` 行も保存され、実行時はこちらが参照されます。

### `クラス一覧`

`2 クラス一覧取得` 実行時に生成・更新されます。

| 列名 | 内容 |
| --- | --- |
| クラス名 | Google Classroom のコース名 |
| コースID | Google Classroom のコース ID |
| 同期対象(1) | 生徒一覧同期の対象にするクラスは `1` |

### `生徒一覧`

`3 生徒一覧取得（同期対象クラス）` 実行時に生成・更新されます。

| 列名 | 内容 |
| --- | --- |
| No | 連番 |
| メールアドレス | 生徒メール |
| 名前 | 生徒名 |
| クラス名 | 所属クラス名 |
| コースID | 投稿先コース ID |
| studentId | Classroom の生徒 ID |

### `対応表`

`4 対応表を作成` 実行時に生成・更新されます。既存の `クラス名` と `メモ` は、同じ `元SS_ID` と `元シート名` の組み合わせであれば再生成時に引き継がれます。

| 列名 | 内容 |
| --- | --- |
| 元SS_ID | フォーム回答元スプレッドシート ID |
| 元スプシ名 | フォーム回答元スプレッドシート名 |
| 元シート名 | フォーム回答元シート名 |
| クラス名 | `クラス一覧` の同期対象クラスから選ぶ |
| courseId | `クラス名` から自動入力される Classroom コース ID |
| メモ | 任意のメモ |

同じメールアドレスの生徒が複数クラスにいる場合は、`評価データ → 送信シート生成` の前に `対応表` で `元SS_ID + 元シート名` とクラスを対応づけてください。

### `評価データ`

`5 Form → 評価データ取り込み` で作られます。列構成は設定ダイアログの内容に応じて再生成されます。

固定列:

- `元SS_ID`
- `元シート名`
- `元行番号`
- `メールアドレス`
- `名前`
- `処理状態`

この後ろに、設定した取り込み項目の列が追加されます。

### `送信シート`

`6 評価データ → 送信シート生成` で作られます。こちらも設定ダイアログの内容に応じて再生成されます。

固定列:

- `元SS_ID`
- `元シート名`
- `元行番号`
- `No`
- `メールアドレス`
- `名前`
- `クラス名`
- `コースID`
- `studentId`
- `送信状態`
- `返信本文`（列名は変更可）

必要に応じて、その後ろに送信用の追加列が並びます。

### `エラー`

送信失敗やフォーム状態更新失敗時に自動生成されます。

| 列名 |
| --- |
| タイムスタンプ |
| シート名 |
| 行番号 |
| メールアドレス |
| 送信状態 |
| エラー種別 |
| エラーメッセージ |

## フォーム回答スプレッドシート側の前提

`設定シート` に登録した各スプレッドシートのうち、シート名が設定した接頭辞で始まるシートを対象に読み込みます。初期値は `フォームの回答` です。

フォーム回答スプレッドシートは `設定シート` の `FORM_SS` 行で管理します。

各対象シートには、少なくとも次の列が必要です。

- メール列
- 名前列
- 送信状態列
- 設定ダイアログで定義した各取り込み項目の元列

ヘッダ名は設定値との完全一致で検索されます。フォーム側の設問名を変えた場合は、先に設定ダイアログの内容も更新してください。

## 送信内容

Google Classroom には、設定ダイアログで設定したテンプレートを元に各生徒向けの本文を投稿します。

`＜score＞` のように書くと差し込みに変換されます。  
`(＜score＞)` のように書けば、括弧付きのまま `(A)` のように表示できます。  
値だけを書く行は、その値が空なら行ごと非表示になります。  
見出し付きの行も、対応する値が空ならその行ごと自動で消えます。

固定トークン:

- `＜student_name＞`
- `＜class_name＞`
- `＜course_id＞`
- `＜row_no＞`

初期設定では、旧版と同じく `評価` `評価理由` `改善点` `提出内容` を本文に含めます。

項目タイプが `score_grade` の場合、数値 `1` から `5` は以下のように変換されます。

| 数値 | 変換後 |
| --- | --- |
| 5 | A |
| 4 | B+ |
| 3 | B |
| 2 | B- |
| 1 | C |

## 状態管理

採点済み判定:

- 設定ダイアログで指定した「採点済み判定に使うフォーム側ヘッダ」に値が入っている行を採点済みとして扱います

未採点判定:

- `メール列名` に値があり、かつ採点済み判定に使う列が空の行を未採点として扱います

### フォーム回答シートの `送信状態`

| 状態 | 意味 |
| --- | --- |
| 空欄 | 未処理 |
| `反映〇` | `評価データ` に取り込み済み |
| `準備〇` | `送信シート` まで生成済み |
| `準備×` | メール不明、生徒一覧未登録などで送信不可 |
| `済` | Classroom 送信済み |
| `送信エラー` | Classroom 側で致命的エラー |

### `評価データ` の `処理状態`

| 状態 | 意味 |
| --- | --- |
| 空欄 | 未処理 |
| `準備〇` | `送信シート` 生成済み |
| `準備×` | 送信不可 |

### `送信シート` の `送信状態`

| 状態 | 意味 |
| --- | --- |
| 空欄 | 未送信 |
| `未` | 一時的エラー。再送対象 |
| `済` | 送信成功 |
| `エラー` | 致命的エラー |

2. `1 初期設定シート作成`
3. `2 クラス一覧取得`
4. `3 生徒一覧取得（同期対象クラス）`
5. `4 対応表を作成`
6. `5 Form → 評価データ取り込み`
7. `6 評価データ → 送信シート生成`
8. `7 生徒へメッセージ送信（Classroom）`

11. `10 送信シートをクリア`
12. `11 エラーログのクリア`

## 推奨トリガー運用

コード冒頭コメントでは、次の時間帯での自動運用が想定されています。

- 5:00-6:00台: `importFromFormsToEval`
- 8:00台: `evalToSendSheet` と `sendMessages`
- 16:00台: `remindUngradedAndErrors`

このトリガー設定自体はコードには含まれていないため、Apps Script のトリガー画面で別途設定してください。

## エラー時の挙動

- Classroom 投稿でレート制限や一時エラーが出た場合は最大 3 回までリトライします
- 一時エラーは `送信シート` 上で `未` として残るため、再実行で再送可能です
- 致命的エラーは `エラー` シートに記録され、フォーム側は `送信エラー` になります
- フォーム回答シートの `送信状態` 更新に失敗した場合も `エラー` シートへ `FORM_UPDATE_ERROR` を記録します

## 注意点

- 生徒のひも付けは `メールアドレス` 基準です
- `生徒一覧` に存在しないメールアドレスは送信対象にできません
- `コースID` が空の生徒は送信できません
- 未採点判定は `メール列名` を回答到着のマーカーとして使います
- 設定を保存すると `評価データ` と `送信シート` は再生成され、既存行は削除されます
- `評価データ` 列名 / `送信シート` 列名を空欄にした場合は、フォーム側ヘッダ名がそのまま使われます
- フォーム側ヘッダ名を変えた場合は、先に設定ダイアログの内容も更新してください
- Classroom 投稿は `INDIVIDUAL_STUDENTS` モードで行われます

## 主要関数

- `classroomdata()`: Classroom のクラス一覧を取得
- `studentdataMulti()`: 同期対象クラスの生徒一覧を取得
- `importFromFormsToEval()`: フォーム回答から採点済みデータを `評価データ` に取り込み
- `evalToSendSheet()`: `評価データ` を送信用に展開
- `sendMessages()`: `送信シート` を元に Classroom へ送信
- `remindUngradedAndErrors()`: 未採点・未送信・エラー件数をメール通知

## 初期セットアップ例

1. 管理用スプレッドシートを作成する
2. このリポジトリの [Code.gs](Code.gs) を Apps Script に貼り付ける
3. スプレッドシートを開き、`1 初期設定シート作成` を実行する
4. `設定シート` に通知先、フォーム回答スプレッドシート URL、対象シート名の接頭辞を入力する
5. `設定を開く` からヘッダー候補を更新し、列設定、取り込み項目、返信テンプレートを保存する
6. 「採点済み判定に使うフォーム側ヘッダ」には、採点時に必ず入力され、生徒に送信する列を設定する
7. 未採点判定は `メール列名` を使うため、フォームでメールアドレスが必ず取得される前提で運用する
8. `2 クラス一覧取得` を実行する
9. 同期したいクラスの `同期対象(1)` に `1` を入れる
10. `3 生徒一覧取得（同期対象クラス）` を実行する
11. フォーム回答シートに、設定したヘッダ名が存在することを確認する
12. 手動実行または時間トリガーで運用する
