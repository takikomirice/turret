# 採点テンプレの全件表示・CSV取り込み

## 変更

- テンプレート全体の「このテンプレートを使用」を撤去し、作成済みの全件を採点画面の選択候補へ表示。選択した1件で採点する動作は維持。
- 採点テンプレは16列。旧17列目「テンプレートを使用」は読み取り時に無視し、次回保存の一括書込みで消去する。未知の追加列は従来どおり拒否し、上書きしない。
- ルールごとの使用・表示、生成後の個別修正は維持。
- 貼り付け、表のコピー、AI依頼文を見出し付きCSVへ変更。貼り付け欄に枠1〜5・出力1〜3の見出しを初期入力する。
- 見出しなし、スプシからのタブ区切りコピー、BOM、引用符付きのカンマ・改行・引用符、空欄・0を扱う。先頭の見出しは除外し、途中の見出しや列数不一致はエラーにする。
- CSVファイルは5MB以内、UTF-8 / Shift_JIS。プレビュー確認後に末尾へ追加し、保存まではシートを更新しない。古いファイル読み込み結果や別テンプレートでのプレビューを誤って反映しない。

## 検証

- `node --test`: 562件成功。CSV境界値、見出し除外、ファイル文字コード・上限・非同期競合、旧非表示テンプレートの取得、旧列消去と失敗時の保持を含む。
- 差分検査と自己レビュー完了。READMEとサンプルパックを更新。配置ファイル数は5つを維持。
- 本人限定確認用GASをv36へ更新。更新前の5ファイルは開始時HEADと一致。更新後の5ファイルを読み戻してローカルとの一致を確認。
- 実画面で初期見出し、CSVプレビュー、見出し除外、カンマ・改行を含む文言と0の取り込み、保存、再読込を確認。
- Sheetsから読み戻し、文言の保持と旧17列目の消去を確認。採点画面の「ルールテンプレ」に作成済みテンプレートが出ることも確認。
- 検証用テンプレート1行は終了後に消去。回答データと採点・返却設定は変更していない。
