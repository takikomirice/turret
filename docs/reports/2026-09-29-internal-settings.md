# 設定の内部保存と管理画面への一本化

## 変更内容

- 設定はScriptPropertiesの`APP_CONFIG`と同内容の`APP_CONFIG_BACKUP`へ保存。Config・設定シート・設定(編集不可)を生成しない。
- 初回管理画面表示時に旧設定を読み込み、内部保存と読み戻しが成功してから旧3シートを削除。空欄による解除も保持する。移行・削除失敗は再読込で再試行し、移行済みの値に古いシートを再適用しない。
- 通常の設定取得からシート読み取りを除去。設定の競合検出、UTF-8 8,000バイト制限、既存の評価・送信データの列構成検証を維持する。
- スプシのメニューは「管理画面を開く」「Web管理画面を開く」の2つ。初期設定・データ整理・手動実行は管理画面内から利用する。
- Web URLは従来どおり`ScriptApp.getService().getUrl()`で取得。リンク、選択できるURL欄、コピー操作を追加。未デプロイ時は導入案内を表示する。
- 次期間用の複製は名簿のみを残し、設定はJSON出力で引き継ぐ。通知先・項目・本文・希望時刻を含め、旧フォームの接続は空にする。複製先でJSONを読み込み、生徒一覧・Webデプロイ・自動実行を設定する。
- 配置ファイルは5のまま。READMEと開発手順を更新。
