## 結果

- 2026-10-01 00:01:29〜00:04:44 JST、確認用GASで34項目すべて成功した。製品コードの追加修正は不要だった。
- 採点保存と採用判断は画面からも使う公開関数 `scoringSaveRows` / `scoringChooseResponses`、送信準備は `prepareSendData` を実行した。実際のスプレッドシートへの書き込み・列移動・旧シート削除・読み戻しを含む。

## 確認範囲

| 範囲 | 確認した内容 |
| --- | --- |
| 初期準備・移行 | フォーム管理の作成、旧2シートの移行・削除、両ブックの右端が「管理」「送信状態」、未完了保存・採用判断の保持 |
| 採点保存 | 列移動前に読み込んだ下書きの保存、列移動後の正しい保存先、保存状態と採用判断の相互保持 |
| 複数ブックの重複 | 2ブックの回答を同一グループとして検出、採用解除、追加回答による判断の無効化、古い比較結果からの更新拒否 |
| 失敗と復旧 | 採用判断の部分保存時は全回答を保留、再試行で復旧、採点失敗時はpendingを永続化、再保存でcompleteへ復旧 |
| 破損・移行失敗 | 壊れた管理JSONと採点値の上書き防止、返却判定の停止、移行先不明なら旧2シートを保持、再試行で最新completeを旧pendingへ戻さない |
| 送信準備 | 未完了保存は準備しない、採用かつ保存完了の1回答だけ準備、最新点数から本文生成、再準備でも送信行を増やさない |
| 独立性・再実行 | 再採点・採用変更でも送信済みを保持、送信準備が管理JSONを変更しない、管理列は1列、旧内部シートを再作成しない |
| 表示・既存データ | 比較表示に管理JSONを含めない、既存ScriptPropertiesの全キー・値を保持、既存運用ブック全シートの値のダイジェスト一致 |
