# 管理・取り込み・採点処理のリファイン

比較元は `6ecaf88`。指摘された6項目を修正した。Apps Scriptへの配置は5ファイル、追加API・Cloud設定変更なし。

## 変更

1. 管理画面の件数・状態表示と操作確認用の指紋計算で、同じ呼び出し内のシート読み取り結果を共有する。実行直前の確認では再取得し、表示後の編集を引き続き検出する。
2. 日次取り込みで、重複判定が取得した回答の生値とシート一覧を共有する。名前補完後の値を使い、呼び出しをまたぐキャッシュは作らない。表示値は取り込み時に取得する。
3. 呼び出し元のない旧単一出力関数と、テスト以外から使われていないサーバーの式評価処理を削除する。式の検証は、実際に画面で使う評価器の結果を固定の期待値と比較する方式へ変更した。JSON検証でも使う共通ヘルパーは残す。
4. 採点保存時の列解決を1回にまとめ、隣接する行の同じ列範囲を一括書き込みする。全対象の保存開始記録を確定してから回答を書き、回答の確定後に完了記録を書く。空欄点数・未使用列・数式を含む間の列は上書きしない。重複する行指定は入力順に処理する。
5. 条件式は最初の評価時に解析し、その結果または構文エラーをテンプレートの読込期間中だけ再利用する。点数ごとの評価結果はキャッシュしない。テンプレートの再取得・解除時に破棄する。
6. 内部シート名の定義を共通化する。採点は外部ブックも全内部名を除外し、取り込みは一部の管理名を運用ブック内だけ除外する、という既存の違いは維持する。

配置コードはコメントを含めて差し引き1,151行減った。
