# v4.0.0 — 管理画面・フォーム配布・予約運用

turretの初期設定からフォーム作成・配布、採点済み回答の取り込み、日次返却までを管理画面から操作できるようにしました。Classroom資料の予約投稿とフォーム受付終了にも対応します。

## 主な変更

- **管理画面の刷新**：管理画面を本人限定Web版へ一本化。スプシの入口は「管理画面を開く」の1つに整理し、別タブで自動表示します。ブラウザーに止められた場合は案内のリンクから開けます。画面ファイルを `Setting.html` へ改名。8ステップのセットアップガイド、進捗表示、入力保持、設定の競合検出を追加。シートへの移動や保守・手動実行の導線を整理しました。
- **設定の再利用**：設定JSONの保存・読み込み、次期間用の複製、共通・項目別の評価変換に対応。返信本文の差し込みを `{student_name}` 形式へ統一し、旧形式との互換性を維持しました。
- **フォームの準備と配布**：ひな形の新規作成、クラス別複製、回答先の接続、採点用追加列、名簿からの名前補完、Classroomへの資料投稿を統合。対応する設問のひな形更新と回答列の整理にも対応します。
- **予約運用**：資料の予約投稿・日時変更・取消・状態照合、フォーム受付終了日時の設定・変更・取消を追加。日時は日本時間で指定し、複数クラスへの一括設定もできます。
- **自動実行と診断**：日次返却の時間帯・開始・停止、実データを使った送信前診断、エラー時の復旧案内を管理画面へ集約しました。
- **信頼性の改善**：二重送信防止、部分失敗からの再試行、結果不明時の照合、設定保存時の既存データ保護、名簿取得の失敗時保護、外部読み取りの削減を実施しました。

## 旧版からの更新

1. 更新前に運用スプレッドシートと既存コードをバックアップし、利用可能な場合は設定JSONも保存してください。
2. Apps Scriptへ `Code.gs`、`Administration.gs`、`Automation.gs`、`Setting.html`、`appsscript.json` の5ファイルを反映してください。手動での貼り付け更新も可能です。旧HTMLファイル `SettingsDialog` は `Setting` に改名し、両方を残さないでください。
3. Web管理画面を利用している場合は、既存デプロイを新しいバージョンへ更新してください。ダイアログ版は廃止し、Webデプロイを必須にしました。未デプロイの場合はスプシの「管理画面を開く」の案内に従ってください。実行ユーザーは自分、アクセスできるユーザーは自分のみです。
4. 管理画面を開くと、旧 `Config`・`設定シート`・`設定(編集不可)` の設定を内部保存へ移行し、読み戻しに成功した後に旧設定シートを削除します。以後は管理画面から設定を変更してください。業務データはシートに保持します。
5. フォーム操作を使う場合はForms・Driveの追加権限を承認してください。権限不足時は `authorizeFormIntegration` を実行できます。フォームのメール収集方式はGoogleフォーム側で「確認済み」に設定します。
6. 回答先・列・本文・日本時間の実行予定を確認し、診断してから運用してください。設定保存やフォーム作成だけでは自動返却を開始しません。

フォーム操作にはFormAppを使用します。Google Forms REST APIや追加のCloudプロジェクト、Cloud Schedulerは不要です。詳しい利用方法は[README](https://github.com/takikomirice/turret/blob/v4.0.0/README.md)を参照してください。

## 予約機能の注意点

- 資料の予約登録時にフォーム受付を開始します。資料公開前でも、URLを知る許可済みユーザーは回答できます。
- 資料予約の取消は下書きを保持し、フォーム受付を変更しません。表示は最終確認時の状態で、「投稿状態を確認」からClassroomと照合できます。
- 受付終了は日次返却とは別の共通タイマーで約5分間隔に確認します。処理の遅延・失敗により停止が遅れる場合があり、厳密な時刻での終了は保証しません。
- 終了予約の取消だけでは受付を再開しません。期限後の再開は、終了予約の変更・取消後に明示的に行ってください。既存回答・採点・返却は保持します。

## 検証

- 全テスト419件、GAS・HTML内JavaScriptの構文検証、差分チェックを実施。
- 指定テストクラスで、フォーム作成・更新、資料予約・変更・取消・実際の公開、タイマーによる受付終了と期限後の再開防止を確認。
- 確認用Web画面は、Web版一本化とメニューからの自動表示を含むバージョン21へ反映済み。実機では自動表示がブラウザーに止められ、代替リンクが表示されることを確認しました。GitHubリリースの公開は、各利用者の本番GASを自動更新しません。
- 実生徒アカウントでの表示、実サービスでの通信障害注入、個別返却・メールの実送信、実GASでの500件処理時間は未確認です。詳細は[予約機能の検証記録](https://github.com/takikomirice/turret/blob/v4.0.0/docs/reports/2026-09-30-scheduling.md)を参照してください。
