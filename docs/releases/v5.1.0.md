# v5.1.0 — 設定JSONの一括移行と入出力画面の改善

管理・採点・採点テンプレートの設定を1つのJSONで引き継げるようにし、個別の入出力も管理画面にまとめました。

## 主な変更

- **4種類の設定ファイル**：管理設定、採点設定、採点テンプレパックを個別に書き出せます。引っ越し用の「全部まとめて」では3種類を1ファイルに保存します。名簿、回答、採点結果、送信履歴、実行中の自動処理は含みません。
- **内容から読み込み種類を判定**：ファイル名に依存せず種類を判定し、置き換える内容を表示してから適用します。旧管理設定JSONと旧採点JSONも読み込めます。個別テンプレパックは追加、一括JSON内のテンプレートは置き換えです。
- **適用時の保護**：内容と読み込み先の変更を照合し、途中で保存に失敗した場合は設定とテンプレートの復元を試みます。管理設定を適用する前には自動実行の停止が必要で、適用後も自動実行は開始しません。
- **接続情報を個別に選択**：ひな形フォームの編集URLと通知先メールを、それぞれ独立してJSONへ含められます。選ばなかった項目と回答先スプレッドシートの接続URLは読み込み先に残ります。旧JSONに含まれる回答先URLは従来どおり読み込めます。
- **画面の整理**：出力と入力を横2列に揃え、出力種類をプルダウン、読み込み欄を1つにしました。「シートを準備」の「前の設定を再利用(JSON)」も同じ入出力画面へ進みます。

## v5.0.0 からの更新

1. 運用スプレッドシートとApps Scriptのコードをバックアップしてください。必要なら現在の設定JSONも保存してください。
2. `Code.gs`、`Administration.gs`、`Setting.html`、`Scoring.html`、`appsscript.json` の5ファイルを反映してください。旧 `Automation.gs` は重複配置しません。
3. Webアプリを新しいバージョンへデプロイしてください。GitHubリリースだけでは利用中のApps Scriptは更新されません。
4. 別運用へ引き継ぐ場合は「設定を保存・出力」で必要な種類と接続情報を選び、複製先で内容を確認して適用してください。名簿や回答などの業務データは別途スプレッドシート側で扱います。ひな形のメール収集方式「確認済み」はフォーム画面で確認してください。

追加のGoogle CloudプロジェクトやGoogle Forms APIは不要です。手動導入と設定JSONの詳しい扱いは[README](../README.md)を参照してください。
