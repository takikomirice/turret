# v6.2.0 — 資料投稿のトピック設定と採点テンプレートの刷新

資料投稿の設定範囲と一括登録を整理し、採点テンプレートを13列の簡潔な形式へ刷新しました。

## 主な変更

- **Classroomのトピック設定**：資料の投稿先トピックを選択・作成でき、反映前に対象と変更内容を確認できます。トピックなしも選択できます。
- **保存範囲と一括登録の整理**：文面・トピック・公開予約・受付終了予約を必要な範囲だけ保存できます。「全部登録」でまとめて登録でき、日付には曜日を表示します。
- **13列の採点テンプレート**：5枠の条件、3つの出力、出力ごとの表示設定、使用する設定に整理しました。出力ごとに上から最初に一致した空欄でない文言を採用し、条件一覧では同じルールをまとめて表示します。
- **表形式の編集**：セル範囲の選択、コピー・貼り付け、行の追加・複製・削除、元に戻す・やり直しに対応しました。各列の「？」とシート見出しのメモから書き方を確認できます。
- **テンプレパックJSON version 2**：ルール・出力ごとの表示設定・各枠の入力制限をまとめて持ち出し、読み込み先に復元できます。入力制限はシート列を増やさず運用環境の設定に保存します。
- **案内の修正**：「名前を反映」の説明を、自動補完の有効化ではなく空欄の補完操作であることが分かるよう整理しました。

## v6.1.0からの更新と互換性

1. 運用スプレッドシート、Apps Scriptのコード、既存テンプレートをバックアップしてください。
2. **旧16/17列の採点テンプレートとversion 1のテンプレパックは未対応です。自動変換しません。** 旧シートを別名で残してから新しい13列の「採点テンプレ」を準備し、旧パックは原本を保存して新しい編集画面で内容を確認しながら作り直してください。旧データを自動削除することはありません。
3. 配置対象は `Code.gs`、`Administration.gs`、`Setting.html`、`Scoring.html`、`appsscript.json` の5ファイルです。既存Webアプリを新しいバージョンへ更新し、画面を開き直してください。
4. トピック操作の利用時にはGoogleの追加承認を求められる場合があります。追加のCloudプロジェクトやAPI有効化は不要です。
5. 入力制限も別環境へ移す場合はversion 2のテンプレパックJSONを使用してください。シートだけのコピーでは入力制限は移りません。採点設定JSONだけにもテンプレート本体は含まれません。
