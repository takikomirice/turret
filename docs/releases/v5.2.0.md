# v5.2.0 — 採点画面の授業日・提出遅れ表示

回答本文の上に授業日と提出状況を追加しました。既存の重複・返却状態と同じ行に並び、縦幅を増やさず確認できます。

## 主な変更

- **固定幅の日付欄**：左側に `2026/09/29（2日遅れ）` と表示します。右側の重複・返却状態の開始位置は固定です。狭い画面では状態行を横スクロールできます。
- **独立した色分け**：遅れの表示と「重複あり」をそれぞれオレンジで強調し、授業日・当日提出・返却状態などは黒で表示します。
- **日付の判定**：回答シートのタイムゾーンで授業日と提出日の暦日差を計算します。当日提出、99日までの遅れ、100日以上の「99日超」、未来の授業日の「授業日前」を表示します。日付欄にカーソルを合わせると提出日時と正確な日数を確認できます。
- **誤入力と不足情報**：授業日の空欄・不正値は「日付不明」、タイムスタンプの不足・不正値は「提出日不明」と表示します。入力値の自動補正や、遅れを理由とする新たな返却制限は行いません。
- **既存データを再利用**：表示用に追加のフォーム取得・スプレッドシート読み込みは行いません。採点保存、重複判断、返却条件は従来どおりです。

## v5.1.0 からの更新

1. 運用スプレッドシートとApps Scriptのコードをバックアップしてください。
2. `Code.gs` と `Scoring.html` を更新し、Webアプリを新しいバージョンへデプロイしてください。全体の配置対象は引き続き5ファイルです。
3. 採点画面を開き直してください。新規ひな形の授業日列は自動検出します。別名の設問を使う場合は、採点設定の「授業日の列」で選択してください。

追加のGoogle Cloud設定やAPI有効化、シート列の追加は不要です。GitHubリリースだけでは利用中のApps Scriptは更新されません。詳細は[README](../../README.md)を参照してください。
