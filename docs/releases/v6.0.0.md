# v6.0.0 — 成績CSV出力と設定の再利用

フォームの準備・配付、採点・返却に続いて、成績をクラス別CSVへ出力できるようになりました。名簿の全員を含め、授業日の補正と重複回答の扱いを確認してからダウンロードします。

## 主な変更

- **成績出力タブ**：既定は全クラス・全期間。先頭列とその順序、授業日列、評価列、名前・出席番号・名簿順を選択します。クラス別のUTF-8 BOM付きCSVを直接作成し、複数クラスはZIPにまとめます。出力用シートは作りません。
- **全生徒・空欄・0点の保持**：未回答の生徒も含め、未回答は空欄、0点は0として出力します。生徒一覧へ任意の出席番号列を追加し、名簿の再取得時も保持します。
- **任意のICS補正**：ICSなしでも日付順に出力できます。ICSを使う場合は全クラスの対応を一画面で設定し、予定にない回答をクラス単位で補正・予定内・予定外に分けます。予定外は右端へ残し、回答単位の例外も設定できます。
- **同日複数授業と再提出**：別授業なら1回目・2回目に割り当て、修正版なら使う回答を選びます。回答や基準日程が変わった場合は判断を再確認し、元回答や採点値は変更しません。
- **下書き・プリセット・JSON**：下書きを自動保存し、名前付きプリセットを登録できます。「すべて」「並び順＋対応関係」「補正ルール」の3種類を、成績出力と既存設定画面の両方で入出力できます。内容の自動識別と、補正ルールの競合選択に対応します。
- **既存管理シートを再利用**：「フォーム管理」は既存履歴を保持して「システム管理」へ改名します。追加Cloud設定・API有効化は不要で、Apps Scriptへの配置は5ファイルのままです。

## v5.2.0からの更新

1. 運用スプレッドシートとApps Scriptのコードをバックアップしてください。
2. 配置対象5ファイルを反映し、既存Webアプリを新しいバージョンへ更新してください。今回の製品コードの変更対象は `Code.gs`、`Administration.gs`、`Setting.html` です。
3. 管理画面を開き直し、「シートを準備」または生徒一覧の再取得で、メールアドレスと名前の間へ「出席番号（任意）」列を追加します。番号は空欄のままでも使えます。
4. 「成績出力」で授業日・評価の列を指定し、必要に応じてICS・並び順を設定してください。最初の出力で日付・重複・プレビューを確認し、設定をプリセットへ保存できます。

管理シートは初期化・保存時に改名します。両方の名前のシートが存在する場合は、自動統合せず停止します。従来の「全部まとめて（引っ越し用）」JSONの形式は維持しており、成績出力設定は専用の3種類で別途書き出します。GitHubリリースだけでは利用中のApps Scriptは更新されません。

## 検証と制約

- 最終確認の `pnpm test` は707件成功。独立レビュー2件でマージを妨げる指摘はありませんでした。旧・新名簿の返却経路、失敗時の保存保持、JSON競合、日付補正・重複・0点・未回答を確認しました。
- GAS実機で架空の2クラス・4名を使い、ICS有無のCSV、補正・採否・プリセット・JSON再適用・名簿移行を確認。ダウンロードしたZIP内のCSVとBOMも検査し、検証データは片付けました。配置5ファイルは確認用Web版46から読み戻して一致を確認済みです。
- ローカルの代替サービスで、500件・5,000件の送信準備と100行の採点保存、500人・100授業日・5万回答の成績集計を確認しました。実GASの処理時間を示す測定ではありません。
- **ICS・JSONのOSファイル選択を含む実画面操作は未確認**です。Chrome拡張の権限変更後も自動操作がタイムアウトしました。ICS解析・JSON適用はGAS実機、ファイル読込イベントの処理は自動テストで確認しています。
- ICSの繰り返し指定（RRULE等）は未対応です。各授業が個別予定として出力されたICSを使ってください。手元の学校出力ICSは25件を正常に解析できました。
- 本番GASへの反映、学校の制限環境、実生徒アカウント、実GASでの大量処理時間は今回の確認対象に含みません。
